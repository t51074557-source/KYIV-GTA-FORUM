KYIV GTA FORUM

Готовий простий форум без MySQL.
Є: реєстрація, вхід, профіль, розділи, створення тем, відповіді.

Запуск: відкрийте index.html.

ВАЖЛИВО: це локальна демо-версія. Дані зберігаються у localStorage браузера, тому різні користувачі не бачать спільну базу на сервері. Для справжнього онлайн-форуму потрібні backend і база даних.
